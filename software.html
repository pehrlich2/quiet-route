Software

The truck on your phone

Big haulers give customers a phone number and a pickup window. We can show customers the actual truck, tell them when it's close, and confirm when their cart has been emptied, using a $10/month tracker and the routes we already plan. Sign-up and billing are built on Stripe, so we never handle card numbers ourselves.

Live truck trackingFrom tracker to a customer's phone

TrackerBouncie or Teltonika in the truck sends a GPS position every few seconds while driving
→
Our serverReceives each position through a webhook and matches it to today's planned stop order from the routing planner
→
ETA + eventsEstimates arrival at each remaining stop. Marks a stop done when the truck stops within ~40 m and then leaves.
→
CustomerSees a live map and gets "15 minutes away" and "Picked up" messages
  • Route-day map: the truck's position (delayed ~1 minute) and "you're stop 12 of 34." Hidden when the truck is off route or at the yard, for safety and privacy.
  • Never show other customers' addresses. A customer sees only the truck and their own place in line.
  • Driver buttons: a phone mounted in the cab with the day's stop list. Stops are marked automatically from GPS. One tap for "cart not out" takes a photo and notifies the customer, which settles the "you skipped me" call before it happens.
  • Why the planner matters: ETAs are only as good as the stop order. Using the routing page's order means the "12 of 34" count is real.

Cost is small. Texts through a provider like Twilio cost about a cent each, plus a one-time US business texting registration (roughly $20–50) and a small monthly fee (estimates; check current pricing). 1,000 customers getting two texts per pickup is about 4,300 texts a month, or ~$40–60. Email is ~$10–15/month. Web push notifications are free. Make email or push the default and text an opt-in.

Why build on Stripe: Stripe does the hard, risky parts: storing cards, recurring charges, failed-payment retries, receipts, and a hosted page where customers update their card or cancel. We build the parts that make us different:

  • Sign-up that checks the address against the E911 points we already downloaded. It confirms we serve the address and shows which route day they'd get.
  • Founding campaign: save the card now (Stripe can store a card without charging it), show progress for each zone, and start charging when the zone launches.
  • Plans: 32, 64 and 96 gal, every other week or weekly, plus compost. Holds for vacations. One-off extra pickups.
  • Operations: send new customers to the routing planner, give the driver a stop list, and flag exceptions.
  • Ask an accountant whether Vermont charges sales tax on trash service and how to record prepayments. Connect Stripe to QuickBooks.

Can we build it in-house with AI?Yes, if we keep it small and keep the money inside Stripe

This is a small web app: a few database tables (customers, addresses, subscriptions, route days, stops, events), Stripe's hosted pages, and a webhook for the tracker. With AI coding tools, a working first version is a few weeks of part-time work (estimate). The routing planner in this project is already the hardest piece.

  • Do: use Stripe's hosted checkout and customer pages, test every billing flow in Stripe's test mode, back up the database nightly, and have logs and an admin page to fix mistakes.
  • Don't: store card numbers, write our own login or password system (use a proven library or a login provider), or build billing logic Stripe already handles.
  • Stack: keep the Python this project already uses (for example FastAPI with SQLite, then Postgres), hosted on a small managed server. The routing planner becomes one module of it.

Build order

  1. Before launch, the campaign: landing page, address check, zone map with progress bars, saved-card pledges and prepaid tiers.
  2. At launch: turn pledges into subscriptions, customer self-service page, route export from the planner, and a driver checklist on a phone.
  3. First season: tracker webhook, live map, "15 minutes away" and "picked up" notifications, and the "cart not out" photo.
  4. Later: compost add-on, extra-pickup orders, referral credits, and member or co-op features if we go that way.
